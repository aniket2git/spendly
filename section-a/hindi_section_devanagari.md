## अध्याय 2 — संधि

**संधि** = दो शब्दों के मेल से होने वाला ध्वनि परिवर्तन।

### 2.1 संधि के तीन प्रकार

| प्रकार | नियम | उदाहरण |
|---|---|---|
| **स्वर संधि** | स्वर + स्वर | विद्या + अर्थी = विद्यार्थी |
| **व्यंजन संधि** | व्यंजन + स्वर/व्यंजन | सत् + जन = सज्जन |
| **विसर्ग संधि** | विसर्ग (ः) + वर्ण | मनः + योग = मनोयोग |

### 2.2 स्वर संधि के पाँच भेद

**1. दीर्घ संधि** — समान स्वर मिलकर दीर्घ हो जाते हैं (अ+अ=आ, इ+इ=ई, उ+उ=ऊ)

| संधि विच्छेद | संधि रूप |
|---|---|
| धर्म + अर्थ | धर्मार्थ |
| विद्या + अर्थी | विद्यार्थी |
| कवि + इन्द्र | कवीन्द्र |
| मुनि + इन्द्र | मुनीन्द्र |
| भानु + उदय | भानूदय |
| सूर्य + अस्त | सूर्यास्त |

**2. गुण संधि** — अ/आ + इ/ई = **ए** ; अ/आ + उ/ऊ = **ओ** ; अ/आ + ऋ = **अर्**

| संधि विच्छेद | संधि रूप |
|---|---|
| नर + इन्द्र | नरेन्द्र |
| देव + इन्द्र | देवेन्द्र |
| सुर + ईश | सुरेश |
| ज्ञान + उपदेश | ज्ञानोपदेश |
| महा + ऋषि | महर्षि |
| देव + ऋषि | देवर्षि |

**3. वृद्धि संधि** — अ/आ + ए/ऐ = **ऐ** ; अ/आ + ओ/औ = **औ**

| संधि विच्छेद | संधि रूप |
|---|---|
| एक + एक | एकैक |
| मत + ऐक्य | मतैक्य |
| जल + ओर्मि | जलौर्मि |
| महा + औषध | महौषध |

**4. यण् संधि** — इ/ई + असमान स्वर = **य्** ; उ/ऊ + असमान स्वर = **व्** ; ऋ + स्वर = **र्**

| संधि विच्छेद | संधि रूप |
|---|---|
| अति + अधिक | अत्यधिक |
| इति + आदि | इत्यादि |
| सु + आगत | स्वागत |
| अनु + एषण | अन्वेषण |
| पितृ + आज्ञा | पित्राज्ञा |

**5. अयादि संधि** — ए + अ = **अय्** ; ऐ + अ = **आय्** ; ओ + अ = **अव्** ; औ + अ = **आव्**

| संधि विच्छेद | संधि रूप |
|---|---|
| ने + अन | नयन |
| गै + अक | गायक |
| पो + अन | पवन |
| पौ + अन | पावन |

### 2.3 व्यंजन संधि — प्रमुख उदाहरण

| संधि विच्छेद | संधि रूप |
|---|---|
| सत् + जन | सज्जन |
| उत् + हार | उद्धार |
| जगत् + नाथ | जगन्नाथ |
| सत् + चरित्र | सच्चरित्र |
| उत् + लास | उल्लास |
| परि + छेद | परिच्छेद |

### 2.4 विसर्ग संधि — प्रमुख उदाहरण

| संधि विच्छेद | संधि रूप |
|---|---|
| मनः + योग | मनोयोग |
| मनः + रथ | मनोरथ |
| निः + चय | निश्चय |
| दुः + ख | दुःख |
| निः + बल | निर्बल |
| यशः + दा | यशोदा |

### 2.5 अभ्यास प्रश्न

**प्रश्न 1.** "विद्यार्थी" में कौन-सी संधि है?
(अ) गुण (ब) वृद्धि (स) **दीर्घ ✔** (द) यण्

*व्याख्या:* विद्या + अर्थी — यहाँ **आ + अ** दो समान स्वर मिलकर दीर्घ **आ** बने। इसलिए **दीर्घ संधि**। **नियम:** जब दोनों स्वर एक ही वर्ग के हों, तो सदैव दीर्घ संधि होती है।

**प्रश्न 2.** "नरेन्द्र" में कौन-सी संधि है?
(अ) दीर्घ (ब) **गुण ✔** (स) वृद्धि (द) अयादि

*व्याख्या:* नर + इन्द्र — यहाँ **अ + इ = ए** हुआ, जो गुण संधि का लक्षण है। तीनों गुण सूत्र एक साथ याद रखें: **अ+इ=ए, अ+उ=ओ, अ+ऋ=अर्**।

**प्रश्न 3.** "सज्जन" में कौन-सी संधि है?
(अ) स्वर संधि (ब) **व्यंजन संधि ✔** (स) विसर्ग संधि (द) कोई नहीं

*व्याख्या:* सत् + जन — यहाँ **व्यंजन (त्)** का परिवर्तन हुआ है, अतः व्यंजन संधि।

**प्रश्न 4.** "मनोयोग" में कौन-सी संधि है?
(अ) दीर्घ (ब) गुण (स) **विसर्ग ✔** (द) यण्

*व्याख्या:* मनः + योग — पहला शब्द **विसर्ग (ः)** पर समाप्त होता है, जो विसर्ग संधि की पहचान है।

**प्रश्न 5.** "स्वागत" का संधि विच्छेद है —
(अ) स्व + आगत (ब) **सु + आगत ✔** (स) स्वा + गत (द) सु + गत

*व्याख्या:* **उ + आ** में उ का **व्** हो गया — यण् संधि।

## अध्याय 3 — समास

**समास** = दो या अधिक शब्दों का मेल, जिसमें बीच के कारक चिह्न लुप्त हो जाते हैं।

### 3.1 समास के छह भेद

| समास | पहचान | उदाहरण |
|---|---|---|
| **अव्ययीभाव** | **पहला** शब्द प्रधान; अव्यय बन जाता है। प्रति, अनु, यथा, भर, आ से आरम्भ | प्रतिदिन, यथाशक्ति, भरपेट, आजीवन, हररोज़ |
| **तत्पुरुष** | **दूसरा** शब्द प्रधान; कारक चिह्न लुप्त | राजकुमार (राजा का कुमार), धर्मग्रंथ, देशभक्ति, गिरिधर |
| **कर्मधारय** | एक शब्द **विशेषण**, दूसरा विशेष्य; दोनों एक ही वस्तु | नीलकमल, महादेव, पीतांबर, चंद्रमुख |
| **द्विगु** | पहला शब्द **संख्यावाची**; समूह का बोध | नवरत्न, चतुर्भुज, त्रिलोक, दोपहर, सप्तर्षि |
| **द्वंद्व** | **दोनों** शब्द प्रधान; बीच में 'और' का भाव | माता-पिता, रात-दिन, सुख-दुःख, राजा-रानी |
| **बहुव्रीहि** | कोई शब्द प्रधान नहीं; **तीसरा अर्थ** निकलता है | दशानन (रावण), लंबोदर (गणेश), चक्रधर (कृष्ण), पीतांबर (कृष्ण) |

### 3.2 पहचान की विधि — इस क्रम में जाँचें

1. प्रति/अनु/यथा/भर/आ से शुरू और अव्यय जैसा? → **अव्ययीभाव**
2. पहला शब्द **संख्या** है? → **द्विगु**
3. **दोनों** समान महत्व के, 'और' का भाव? → **द्वंद्व**
4. किसी **तीसरी वस्तु/व्यक्ति** का बोध? → **बहुव्रीहि**
5. एक शब्द दूसरे का **विशेषण**, दोनों एक ही वस्तु? → **कर्मधारय**
6. अन्यथा **दूसरा** शब्द प्रधान → **तत्पुरुष**

### 3.3 अभ्यास प्रश्न

**प्रश्न 1.** "दशानन" में कौन-सा समास है?
(अ) द्विगु (ब) कर्मधारय (स) तत्पुरुष (द) **बहुव्रीहि ✔**

*व्याख्या:* "दशानन" का शाब्दिक अर्थ "दस मुख" है, परन्तु यह **रावण** का बोध कराता है — एक **तीसरी वस्तु** जिसका नाम किसी घटक में नहीं है। यही बहुव्रीहि की परिभाषा है।
**जाल:** "दश" संख्या देखकर द्विगु चुनने की भूल न करें। द्विगु में **समूह स्वयं** अर्थ होता है (जैसे नवरत्न = नौ रत्नों का समूह), तीसरी वस्तु नहीं।

**प्रश्न 2.** "माता-पिता" में कौन-सा समास है?
(अ) तत्पुरुष (ब) **द्वंद्व ✔** (स) द्विगु (द) बहुव्रीहि

*व्याख्या:* दोनों शब्द समान महत्व के हैं और बीच में **'और'** का भाव है। ऐसे समास प्रायः **योजक चिह्न (-)** के साथ लिखे जाते हैं — यह एक उपयोगी संकेत है।

**प्रश्न 3.** "प्रतिदिन" में कौन-सा समास है?
(अ) तत्पुरुष (ब) द्विगु (स) **अव्ययीभाव ✔** (द) कर्मधारय

*व्याख्या:* **प्रति** उपसर्ग से आरम्भ और क्रिया-विशेषण की तरह प्रयोग — अव्ययीभाव।

**प्रश्न 4.** "नीलकमल" में कौन-सा समास है?
(अ) द्वंद्व (ब) बहुव्रीहि (स) **कर्मधारय ✔** (द) द्विगु

*व्याख्या:* "नील" (विशेषण) "कमल" (विशेष्य) का गुण बता रहा है, और दोनों **एक ही वस्तु** की ओर संकेत करते हैं।

**प्रश्न 5.** "चतुर्भुज" में कौन-सा समास है?
(अ) कर्मधारय (ब) **द्विगु ✔** (स) द्वंद्व (द) अव्ययीभाव

*व्याख्या:* पहला शब्द **चतुर्** (संख्यावाची) है और समूह का बोध होता है — द्विगु।

## अध्याय 4 — उपसर्ग एवं प्रत्यय

### 4.1 प्रमुख उपसर्ग (शब्द के **आरम्भ** में)

| उपसर्ग | अर्थ | उदाहरण |
|---|---|---|
| प्र | आगे, अधिक | प्रबल, प्रगति, प्रयोग |
| अप | बुरा, दूर | अपमान, अपव्यय, अपकार |
| सम् | साथ | संयोग, सम्मेलन, संग्रह |
| नि | नीचे, बिना | निवास, निषेध, निबंध |
| निर्/निस् | बिना | निर्धन, निश्चय, निर्बल |
| दुर्/दुस् | बुरा, कठिन | दुर्गुण, दुष्कर्म, दुर्दशा |
| वि | विशेष, अलग | विशेष, वियोग, विदेश |
| अधि | ऊपर, अधिक | अधिकार, अध्यक्ष, अधिपति |
| अनु | पीछे, अनुसार | अनुसार, अनुवाद, अनुज |
| अति | अधिक | अत्यंत, अतिरेक, अत्याचार |
| अ/अन् | नहीं | अभाव, अन्याय, अनादि |
| सु | अच्छा | सुगम, सुशील, सुपुत्र |
| प्रति | ओर, विरुद्ध | प्रतिदिन, प्रतिवाद, प्रतिकूल |
| उप | निकट, गौण | उपवन, उपाध्यक्ष, उपकार |
| परि | चारों ओर | परिक्रमा, परिवार, परिणाम |

### 4.2 प्रमुख प्रत्यय (शब्द के **अंत** में)

| प्रत्यय | कार्य | उदाहरण |
|---|---|---|
| -ता | भाववाचक संज्ञा | मानवता, सुंदरता, मूर्खता |
| -पन | भाववाचक संज्ञा | बचपन, लड़कपन, अपनापन |
| -वाला | स्वामी/करने वाला | गाड़ीवाला, धनवाला |
| -कार | करने वाला | कलाकार, चित्रकार, पत्रकार |
| -इक | विशेषण | सामाजिक, धार्मिक, ऐतिहासिक |
| -हीन | रहित | बलहीन, धनहीन, गुणहीन |
| -मान/-वान | युक्त | बुद्धिमान, धनवान, गुणवान |
| -ई/-इन | संबंधित | देसी, ज्ञानी, मालिन |

**कृत् प्रत्यय** — क्रिया की धातु में लगता है। जैसे: लिख + अक = **लेखक**
**तद्धित प्रत्यय** — संज्ञा/सर्वनाम/विशेषण में लगता है। जैसे: मानव + ता = **मानवता**

### 4.3 अभ्यास प्रश्न

**प्रश्न 1.** "निर्धन" में उपसर्ग है —
(अ) निर्ध (ब) **निर् ✔** (स) धन (द) अन्

*व्याख्या:* **निर्** = बिना, **धन** = मूल शब्द। अर्थात "धन से रहित"। नकारात्मक उपसर्ग: **निर्, निस्, अ, अन्, दुर्, अप**।

**प्रश्न 2.** "मानवता" में प्रत्यय है —
(अ) -वान (ब) -इक (स) **-ता ✔** (द) -पन

*व्याख्या:* मानव + **ता**। यह संज्ञा को **भाववाचक संज्ञा** बनाता है, और संज्ञा में लगने के कारण **तद्धित** प्रत्यय है।

## अध्याय 5 — कारक, लिंग एवं वचन

### 5.1 आठ कारक

| कारक | अर्थ | विभक्ति चिह्न |
|---|---|---|
| कर्ता | करने वाला | ने |
| कर्म | जिस पर क्रिया का प्रभाव | को |
| करण | साधन ("के द्वारा") | से, के द्वारा |
| सम्प्रदान | जिसके लिए | के लिए, को |
| अपादान | अलगाव ("से") | से (अलग होने के अर्थ में) |
| संबंध | स्वामित्व | का, के, की |
| अधिकरण | स्थान | में, पर |
| सम्बोधन | पुकारना | हे, अरे, ओ |

> **सबसे महत्वपूर्ण अंतर — करण vs अपादान**
> दोनों में **"से"** लगता है, और परीक्षा में यही पूछा जाता है।
> **करण** = साधन के अर्थ में → *कलम **से** लिखा* (कलम साधन है)
> **अपादान** = अलग होने के अर्थ में → *पेड़ **से** पत्ता गिरा* (पेड़ से अलग हुआ)
> **प्रश्न पूछें:** "से" काम कर रहा है (करण) या स्रोत बता रहा है जिससे अलग हो रहे हैं (अपादान)?

### 5.2 लिंग एवं वचन

**लिंग** — हिंदी में दो: **पुल्लिंग** एवं **स्त्रीलिंग**। अंग्रेज़ी के विपरीत, निर्जीव वस्तुओं का भी लिंग होता है — *किताब* स्त्रीलिंग, *मकान* पुल्लिंग।

**वचन** — दो: **एकवचन** एवं **बहुवचन**।

| एकवचन | बहुवचन |
|---|---|
| लड़का | लड़के |
| किताब | किताबें |
| नदी | नदियाँ |
| चिड़िया | चिड़ियाँ |
| कविता | कविताएँ |
| वस्तु | वस्तुएँ |

| अशुद्धि का प्रकार | अशुद्ध → शुद्ध |
|---|---|
| लिंग सम्बन्धी | मेरी पुस्तक अच्छा है → मेरी पुस्तक **अच्छी** है |

| वर्तनी | अनुश्शासन → **अनुशासन** |
| क्रम दोष | केवल मैं ही गया → **मैं ही गया** |

> **दो जाँचें जो अधिकांश अशुद्धियाँ पकड़ लेती हैं**
>
> **जाँच 1 — लिंग मेल।** संज्ञा ढूँढें, उसका लिंग तय करें, फिर देखें कि हर विशेषण और क्रिया उससे मेल खाती है या नहीं। सबसे ज़्यादा अशुद्धियाँ यहीं होती हैं।
>
> **जाँच 2 — विभक्ति।** देखें कि कारक चिह्न (ने, को, से, में, पर) वाक्य की आवश्यकता से मेल खाता है या नहीं।

## अध्याय 12 — अपठित गद्यांश

### 12.1 विधि

**चरण 1.** पहले **प्रश्न** पढ़ें — जिससे पता चले कि क्या खोजना है।
**चरण 2.** गद्यांश एक बार पढ़ें — विषय और भाव समझने के लिए।
**चरण 3.** तथ्यात्मक प्रश्नों के उत्तर पंक्ति ढूँढकर दें।
**चरण 4.** **शीर्षक** का प्रश्न **सबसे अंत** में करें।
**चरण 5.** शीर्षक वह चुनें जो **पूरे** गद्यांश को समेटे — न किसी एक अनुच्छेद का, न गद्यांश से अधिक व्यापक।

> **स्वर्ण नियम:** उत्तर **गद्यांश से** ही आना चाहिए। यदि कोई विकल्प सामान्य ज्ञान के अनुसार सही है परन्तु गद्यांश में नहीं लिखा है, तो वह **गलत** है।

### 12.2 शीर्षक के प्रश्न में सावधानी

अभ्यर्थी सबसे रोचक विकल्प चुन लेते हैं, सबसे **प्रतिनिधि** विकल्प नहीं। प्रत्येक विकल्प पर दो प्रश्न लगाएँ:

1. क्या यह **पूरे** गद्यांश को समेटता है?
2. क्या यह गद्यांश से **अधिक** दावा करता है?

सही उत्तर सब कुछ समेटता है और अतिरिक्त कुछ नहीं कहता।

### 13.1 19-20 अंक लाने की पाँच आदतें
