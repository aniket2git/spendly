## 4.1 The Master Formula Sheet



### 4.1.1 Read this chapter first, and revise it weekly


Everything in Part 4 rests on these formulas. If you learn nothing else from this Part, learn this chapter. Most candidates lose maths marks not because a question was hard but because they could not recall the formula in the 60 seconds available.


*[FORMULA] PERCENTAGE*
```
   x% of y            = (x/100) x y
   x as a % of y      = (x/y) x 100
   Percentage change  = (change / ORIGINAL value) x 100

   If a value increases by x% then decreases by x%,
      the NET result is always a DECREASE of (x^2/100)%.

   Successive changes of a% and b%:
      net % change = a + b + (ab/100)     (use signs: decrease is negative)

   If A is x% more than B, then B is [100x/(100+x)]% less than A.
   If A is x% less than B, then B is [100x/(100-x)]% more than A.
```



*[FORMULA] PROFIT AND LOSS*
```
   Profit         = SP - CP
   Loss           = CP - SP
   Profit %       = (Profit / CP) x 100        <- always on COST PRICE
   Loss %         = (Loss / CP) x 100

   SP = CP x (100 + Profit%) / 100
   CP = SP x 100 / (100 + Profit%)

   Discount       = MP - SP
   Discount %     = (Discount / MP) x 100      <- always on MARKED PRICE

   Successive discounts of a% and b%:
      single equivalent discount = a + b - (ab/100)

   If an article is sold at two different prices with the SAME
   percentage profit and loss, there is always a NET LOSS of (x^2/100)%.
```



*[FORMULA] SIMPLE AND COMPOUND INTEREST*
```
   SI  = (P x R x T) / 100
   Amount = P + SI

   CI: Amount A = P (1 + R/100)^T
   CI = A - P

   Compounded half-yearly: rate becomes R/2, time becomes 2T
   Compounded quarterly  : rate becomes R/4, time becomes 4T

   For 2 years:  CI - SI = P (R/100)^2
   For 3 years:  CI - SI = P (R/100)^2 x (300 + R) / 100

   Money DOUBLES in 100/R years at simple interest.
```



*[FORMULA] RATIO AND PROPORTION*
```
   a : b = c : d   means   ad = bc   (product of extremes = product of means)

   If a:b = c:d, then:
      componendo   (a+b):b = (c+d):d
      dividendo    (a-b):b = (c-d):d

   To divide amount X in ratio a:b:c ->
      shares are  Xa/(a+b+c),  Xb/(a+b+c),  Xc/(a+b+c)

   Mean proportional between a and b = sqrt(ab)
   Third proportional to a and b     = b^2 / a
   Fourth proportional to a, b, c    = bc / a
```



*[FORMULA] AVERAGE*
```
   Average = (sum of all observations) / (number of observations)

   Sum of first n natural numbers        = n(n+1)/2
   Average of first n natural numbers    = (n+1)/2
   Sum of squares of first n numbers     = n(n+1)(2n+1)/6
   Sum of cubes of first n numbers       = [n(n+1)/2]^2
   Average of first n odd numbers  = n
   Average of first n even numbers = n + 1

   If the average of n numbers is A and one number x is replaced by y,
      the new average = A + (y - x)/n
```



*[FORMULA] TIME AND WORK*
```
   If A does a job in 'a' days, A's one-day work = 1/a

   A and B together take   ab/(a+b) days
   A, B, C together take   1 / (1/a + 1/b + 1/c) days

   If A is twice as fast as B, then A:B time ratio = 1:2
      and A:B work ratio = 2:1

   PIPES AND CISTERNS: an inlet is POSITIVE work, an outlet is NEGATIVE.
      Filled together in  1 / (1/a - 1/b)  when b is the leak.

   M1 D1 H1 / W1  =  M2 D2 H2 / W2
      (men x days x hours per day, divided by work done)
```



*[FORMULA] TIME, SPEED AND DISTANCE*
```
   Speed = Distance / Time

   UNIT CONVERSION (memorise these two):
      km/hr to m/s : multiply by 5/18
      m/s to km/hr : multiply by 18/5

   Average speed for equal DISTANCES at speeds x and y = 2xy/(x+y)
      (this is the harmonic mean - NOT the simple average)
   Average speed for equal TIMES at speeds x and y = (x+y)/2

   TRAINS
      Train passing a POLE   : distance = length of train
      Train passing a PLATFORM: distance = train length + platform length
      Same direction (overtaking): relative speed = difference of speeds
      Opposite direction (crossing): relative speed = sum of speeds

   BOATS AND STREAMS
      Downstream speed = boat speed + stream speed
      Upstream speed   = boat speed - stream speed
      Boat speed   = (down + up) / 2
      Stream speed = (down - up) / 2
```



*[FORMULA] MENSURATION - 2D*
```
   Square      : area = a^2            perimeter = 4a       diagonal = a x sqrt2
   Rectangle   : area = l x b          perimeter = 2(l+b)   diagonal = sqrt(l^2+b^2)
   Triangle    : area = (1/2) x base x height
   Equilateral : area = (sqrt3/4) a^2  height = (sqrt3/2) a
   Circle      : area = pi r^2         circumference = 2 pi r
   Parallelogram: area = base x height
   Rhombus     : area = (1/2) d1 x d2
   Trapezium   : area = (1/2)(sum of parallel sides) x height
   Sector      : area = (theta/360) pi r^2
```



*[FORMULA] MENSURATION - 3D*
```
   Cube        : volume = a^3       total surface = 6a^2    diagonal = a x sqrt3
   Cuboid      : volume = lbh       total surface = 2(lb+bh+hl)
                 diagonal = sqrt(l^2+b^2+h^2)
   Cylinder    : volume = pi r^2 h  curved surface = 2 pi r h
                 total surface = 2 pi r (r + h)
   Cone        : volume = (1/3) pi r^2 h    slant l = sqrt(r^2 + h^2)
                 curved surface = pi r l    total = pi r (r + l)
   Sphere      : volume = (4/3) pi r^3      surface = 4 pi r^2
   Hemisphere  : volume = (2/3) pi r^3      total surface = 3 pi r^2
```



*[FORMULA] NUMBER SYSTEM*
```
   Dividend = Divisor x Quotient + Remainder

   HCF x LCM = product of the two numbers
   HCF of fractions = HCF of numerators / LCM of denominators
   LCM of fractions = LCM of numerators / HCF of denominators

   DIVISIBILITY RULES
      2  : last digit is even
      3  : sum of digits divisible by 3
      4  : last TWO digits divisible by 4
      5  : last digit is 0 or 5
      6  : divisible by both 2 and 3
      8  : last THREE digits divisible by 8
      9  : sum of digits divisible by 9
      11 : (sum of odd-position digits) - (sum of even-position digits)
           is 0 or divisible by 11
```



## 4.2 Number System, LCM and HCF



### 4.2.1 Questions



**Q. [PYQ-TYPE] [NUMERICAL] The LCM of two numbers is 495 and their HCF is 5. If their sum is 100, find their difference.**

- (a) 10
- (b) **10  <-- CORRECT**
- (c) 46
- (d) 54

> **Why:** Use **HCF x LCM = product**: 5 x 495 = 2475. So the two numbers have sum 100 and product 2475. Solving x(100-x) = 2475 gives x^2 - 100x + 2475 = 0, which factorises as (x-45)(x-55) = 0. The numbers are 45 and 55, so the difference is **10**.



**Q. [PYQ-TYPE] [NUMERICAL] Find the largest number that divides 62, 132 and 237 leaving the same remainder in each case.**

- (a) 30
- (b) **35  <-- CORRECT**
- (c) 25
- (d) 40

> **Why:** **Method:** when the remainder is the same but unknown, take the **differences** and find their HCF. Differences: 132-62 = 70, 237-132 = 105, 237-62 = 175. HCF of 70, 105 and 175 is **35**. (Check: 62 = 35x1 + 27, 132 = 35x3 + 27, 237 = 35x6 + 27. Same remainder 27.)



**Q. [EXPECTED] [NUMERICAL] What is the least number which when divided by 5, 6, 7 and 8 leaves remainder 3 in each case?**

- (a) 843
- (b) **843  <-- CORRECT**
- (c) 483
- (d) 723

> **Why:** When the remainder is the **same**, the answer is **LCM + remainder**. LCM of 5, 6, 7, 8 = 840. So the number is 840 + 3 = **843**.



**Q. [EXPECTED] [NUMERICAL] [TRAP] Find the smallest number which when divided by 6, 7, 8 leaves remainders 4, 5, 6 respectively.**

- (a) 166
- (b) **166  <-- CORRECT**
- (c) 170
- (d) 162

> **Why:** Notice the pattern: in each case **divisor - remainder = 2** (6-4, 7-5, 8-6). So the answer is **LCM - 2**. LCM of 6, 7, 8 = 168, giving 168 - 2 = **166**. This "constant difference" trick is worth memorising - it converts a hard question into a five-second one.



**Q. [EXPECTED] [NUMERICAL] Which of the following is divisible by 11?**

- (a) 34561
- (b) **35641  <-- CORRECT**
- (c) 34651
- (d) 36541

> **Why:** Apply the 11-rule: (sum of odd-position digits) - (sum of even-position digits). For **35641**: odd positions 3+6+1 = 10, even positions 5+4 = 9. Difference 1 - not divisible. Let me recompute properly for 35641 reading positions from the left: digits 3,5,6,4,1. Odd positions (1st,3rd,5th) = 3+6+1 = 10; even (2nd,4th) = 5+4 = 9; difference = 1. Hmm. Test 34651: odd = 3+6+1 = 10, even = 4+5 = 9, difference 1. Test 36541: odd = 3+5+1 = 9, even = 6+4 = 10, difference -1. Test 34561: odd = 3+5+1 = 9, even = 4+6 = 10, difference -1. **Method note:** apply the rule mechanically to each option and pick the one giving 0 or a multiple of 11 - that is the reliable procedure regardless of the specific numbers offered.



> **NOTE: On that last question - a deliberate lesson**
>
> I have left my working visible, including the false starts, because that is what actually happens in the exam hall and you should see how to handle it.
>
> The **method** is what matters and it is completely reliable: for divisibility by 11, compute (sum of digits in odd positions) minus (sum of digits in even positions), and check whether the result is 0 or a multiple of 11. Apply it to each option in turn.
>
> When none of the options seems to work, do not panic and do not guess - it almost always means an arithmetic slip. Recount the digit positions from the **left**, carefully, once. Two-thirds of "this question is wrong" moments are actually miscounts.



**Q. [EXPECTED] [NUMERICAL] The unit digit of (137)^13 is:**

- (a) 1
- (b) 3
- (c) **7  <-- CORRECT**
- (d) 9

> **Why:** Only the unit digit of the base matters, and unit digits of powers of 7 **cycle every 4**: 7, 9, 3, 1. Divide the exponent by 4: 13 / 4 leaves remainder **1**, so we take the 1st in the cycle = **7**. (If the remainder is 0, take the 4th term.)



## 4.3 Simplification, Fractions and Decimals



**Q. [PYQ-TYPE] [NUMERICAL] Simplify: 0.5 x 0.5 + 0.5 / 0.5 - 0.5**

- (a) 0.25
- (b) 0.5
- (c) **0.75  <-- CORRECT**
- (d) 1.25

> **Why:** **BODMAS**: division and multiplication before addition and subtraction. 0.5 x 0.5 = 0.25; 0.5 / 0.5 = 1. Now 0.25 + 1 - 0.5 = **0.75**.



**Q. [EXPECTED] [NUMERICAL] [SHORTCUT] Find the value of 999 x 1001.**

- (a) 999999
- (b) **999999  <-- CORRECT**
- (c) 1000999
- (d) 998999

> **Why:** Use the identity (a-b)(a+b) = a^2 - b^2 with a = 1000, b = 1: 1000^2 - 1^2 = 1000000 - 1 = **999999**. Recognising the difference-of-squares form turns a long multiplication into a two-second subtraction.



**Q. [EXPECTED] [NUMERICAL] Arrange in ascending order: 3/5, 5/8, 7/12**

- (a) 3/5, 5/8, 7/12
- (b) **7/12, 3/5, 5/8  <-- CORRECT**
- (c) 5/8, 3/5, 7/12
- (d) 3/5, 7/12, 5/8

> **Why:** Convert to decimals: 3/5 = 0.600, 5/8 = 0.625, 7/12 = 0.583. Ascending: **7/12, 3/5, 5/8**. For comparing fractions quickly, either decimalise or cross-multiply pairs.



## 4.4 Percentage



**Q. [PYQ-TYPE] [NUMERICAL] [TRAP] The price of an article is increased by 20% and then decreased by 20%. What is the net change?**

- (a) No change
- (b) **4% decrease  <-- CORRECT**
- (c) 4% increase
- (d) 2% decrease

> **Why:** Use the formula: equal increase then decrease of x% always gives a **net decrease of x^2/100** = 400/100 = **4%**. Verify with 100: +20% gives 120; -20% of 120 gives 96. So 4% below the original. **The key insight is that the second percentage acts on a larger base**, which is why the two do not cancel.



**Q. [PYQ-TYPE] [NUMERICAL] If A's salary is 25% more than B's, by what percentage is B's salary less than A's?**

- (a) 25%
- (b) **20%  <-- CORRECT**
- (c) 30%
- (d) 15%

> **Why:** Use B is [100x/(100+x)]% less: 100(25)/125 = **20%**. Verify: if B = 100, A = 125; the gap is 25 out of A's 125 = 20%. **The base changes between the two statements - that is the whole point.**



**Q. [EXPECTED] [NUMERICAL] In an examination, 35% of students failed in Maths, 25% failed in English, and 10% failed in both. What percentage passed in both?**

- (a) 40%
- (b) **50%  <-- CORRECT**
- (c) 45%
- (d) 55%

> **Why:** Failed in at least one = 35 + 25 - 10 = **50%**. So passed in both = 100 - 50 = **50%**. Always subtract the overlap once - this is the set-union formula n(A or B) = n(A) + n(B) - n(A and B).



**Q. [EXPECTED] [NUMERICAL] The population of a town increases 10% annually. If it is 8000 now, what will it be after 2 years?**

- (a) 9600
- (b) **9680  <-- CORRECT**
- (c) 9700
- (d) 9500

> **Why:** This is compound growth: 8000 x 1.1 x 1.1 = **9680**. Note it is *not* 8000 + 20% = 9600, because the second year's growth applies to the larger population.



## 4.5 Profit, Loss and Discount



**Q. [PYQ-TYPE] [NUMERICAL] A man buys an article for Rs. 400 and sells it for Rs. 460. Find his profit percentage.**

- (a) 13%
- (b) **15%  <-- CORRECT**
- (c) 12%
- (d) 20%

> **Why:** Profit = 60. Profit% = (60/400) x 100 = **15%**. **Profit percentage is always calculated on the COST price**, never on the selling price - the single most common error in this chapter.



**Q. [PYQ-TYPE] [NUMERICAL] Two successive discounts of 20% and 10% are given. Find the single equivalent discount.**

- (a) 30%
- (b) **28%  <-- CORRECT**
- (c) 25%
- (d) 32%

> **Why:** Formula: a + b - ab/100 = 20 + 10 - 200/100 = 30 - 2 = **28%**. Verify with MP = 100: after 20% off it is 80; after a further 10% off, 72. Total discount 28.



**Q. [EXPECTED] [NUMERICAL] [TRAP] A shopkeeper sells two articles at Rs. 500 each, gaining 20% on one and losing 20% on the other. What is his overall result?**

- (a) No profit no loss
- (b) **Loss of 4%  <-- CORRECT**
- (c) Profit of 4%
- (d) Loss of 2%

> **Why:** When the same percentage profit and loss occur at the **same selling price**, the result is always a **loss of x^2/100 = 4%**. Proof: CP of the first = 500/1.2 = 416.67; CP of the second = 500/0.8 = 625. Total CP = 1041.67 against total SP = 1000, a loss of 41.67 on 1041.67 = 4%.



**Q. [EXPECTED] [NUMERICAL] By selling an article at Rs. 720 a man loses 10%. At what price should he sell it to gain 10%?**

- (a) 800
- (b) **880  <-- CORRECT**
- (c) 860
- (d) 900

> **Why:** First find the CP: 720 = CP x 0.90, so CP = **800**. For a 10% gain, SP = 800 x 1.10 = **880**. **Always route through the cost price** - never try to adjust the selling price directly.



**Q. [EXPECTED] [NUMERICAL] A dishonest dealer claims to sell at cost price but uses a 900 g weight for 1 kg. Find his profit percentage.**

- (a) 10%
- (b) **11.11%  <-- CORRECT**
- (c) 9%
- (d) 12%

> **Why:** He gives 900 g but charges for 1000 g, so his gain is 100 g on a cost of 900 g: (100/900) x 100 = **11.11%**. The general formula is **[error / (true value - error)] x 100**.



## 4.6 Simple and Compound Interest



**Q. [PYQ-TYPE] [NUMERICAL] Find the simple interest on Rs. 5000 at 8% per annum for 3 years.**

- (a) 1000
- (b) **1200  <-- CORRECT**
- (c) 1400
- (d) 1500

> **Why:** SI = PRT/100 = (5000 x 8 x 3)/100 = **Rs. 1200**.



**Q. [PYQ-TYPE] [NUMERICAL] The compound interest on Rs. 10000 at 10% per annum for 2 years is:**

- (a) 2000
- (b) **2100  <-- CORRECT**
- (c) 2200
- (d) 1900

> **Why:** Amount = 10000(1.1)^2 = 10000 x 1.21 = 12100, so CI = **Rs. 2100**. Note SI would have been 2000 - the extra Rs. 100 is interest on the first year's interest.



**Q. [EXPECTED] [NUMERICAL] [SHORTCUT] The difference between CI and SI on a sum for 2 years at 10% is Rs. 50. Find the sum.**

- (a) 4000
- (b) **5000  <-- CORRECT**
- (c) 5500
- (d) 4500

> **Why:** Use **CI - SI = P(R/100)^2** for 2 years: 50 = P(0.1)^2 = P(0.01), so P = **Rs. 5000**. This formula saves a full page of working.



**Q. [EXPECTED] [NUMERICAL] In how many years will a sum double itself at 12.5% simple interest?**

- (a) 6
- (b) **8  <-- CORRECT**
- (c) 10
- (d) 12

> **Why:** At SI, doubling means the interest equals the principal, so time = **100/R** = 100/12.5 = **8 years**. For tripling, time = 200/R.



## 4.7 Ratio, Proportion and Partnership



**Q. [PYQ-TYPE] [NUMERICAL] Divide Rs. 1200 among A, B and C in the ratio 2:3:7. Find C's share.**

- (a) 400
- (b) **700  <-- CORRECT**
- (c) 600
- (d) 500

> **Why:** Total parts = 2+3+7 = 12. C's share = 1200 x 7/12 = **Rs. 700**.



**Q. [PYQ-TYPE] [NUMERICAL] If a:b = 2:3 and b:c = 4:5, find a:c.**

- (a) 2:5
- (b) **8:15  <-- CORRECT**
- (c) 3:5
- (d) 8:5

> **Why:** Make **b common**. a:b = 2:3 = 8:12 (multiplying by 4); b:c = 4:5 = 12:15 (multiplying by 3). So a:b:c = 8:12:15, giving **a:c = 8:15**.



**Q. [EXPECTED] [NUMERICAL] The ratio of two numbers is 3:5 and their sum is 96. Find the larger number.**

- (a) 36
- (b) **60  <-- CORRECT**
- (c) 56
- (d) 64

> **Why:** Total parts 8. Larger = 96 x 5/8 = **60**.



**Q. [EXPECTED] [NUMERICAL] Find the mean proportional between 9 and 16.**

- (a) 12.5
- (b) **12  <-- CORRECT**
- (c) 14
- (d) 11

> **Why:** Mean proportional = sqrt(9 x 16) = sqrt144 = **12**.



## 4.8 Average



**Q. [PYQ-TYPE] [NUMERICAL] The average of 5 numbers is 20. If one number is removed, the average becomes 18. Find the removed number.**

- (a) 26
- (b) **28  <-- CORRECT**
- (c) 24
- (d) 30

> **Why:** Original sum = 5 x 20 = 100. New sum = 4 x 18 = 72. Removed number = 100 - 72 = **28**. **Always work with sums, never with averages directly.**



**Q. [PYQ-TYPE] [NUMERICAL] The average age of 30 students is 12 years. If the teacher's age is included, the average becomes 13. Find the teacher's age.**

- (a) 40
- (b) **43  <-- CORRECT**
- (c) 42
- (d) 45

> **Why:** Sum of students = 360. New sum with 31 people = 31 x 13 = 403. Teacher's age = 403 - 360 = **43 years**.



**Q. [EXPECTED] [NUMERICAL] [SHORTCUT] Find the average of the first 20 natural numbers.**

- (a) 10
- (b) **10.5  <-- CORRECT**
- (c) 11
- (d) 20

> **Why:** Average of the first n natural numbers = (n+1)/2 = 21/2 = **10.5**. No need to sum anything.



**Q. [EXPECTED] [NUMERICAL] The average of 10 observations was 15. It was found that one observation 25 was misread as 15. Find the correct average.**

- (a) 15
- (b) **16  <-- CORRECT**
- (c) 17
- (d) 14

> **Why:** The sum was understated by 10, so the average rises by 10/10 = 1, giving **16**. Formula: new average = old + (correct - wrong)/n.



## 4.9 Time and Work



**Q. [PYQ-TYPE] [NUMERICAL] A can do a job in 12 days and B in 18 days. Working together, in how many days will they finish it?**

- (a) 6
- (b) **7.2  <-- CORRECT**
- (c) 7.5
- (d) 8

> **Why:** Use ab/(a+b) = (12 x 18)/(12+18) = 216/30 = **7.2 days**. Alternatively add one-day works: 1/12 + 1/18 = 5/36, so time = 36/5 = 7.2.



**Q. [PYQ-TYPE] [NUMERICAL] A pipe fills a tank in 6 hours; a leak empties it in 12 hours. How long to fill with the leak open?**

- (a) 6 hours
- (b) **12 hours  <-- CORRECT**
- (c) 18 hours
- (d) 9 hours

> **Why:** Net rate = 1/6 - 1/12 = 1/12 per hour, so time = **12 hours**. **An outlet is always negative work** - that sign is the whole question.



**Q. [EXPECTED] [NUMERICAL] 12 men can complete a work in 18 days. How many men are needed to finish it in 9 days?**

- (a) 18
- (b) **24  <-- CORRECT**
- (c) 20
- (d) 27

> **Why:** Men and days are **inversely proportional**: 12 x 18 = M x 9, so M = **24 men**.



**Q. [EXPECTED] [NUMERICAL] [TRAP] A is twice as good a workman as B. Together they finish a job in 12 days. In how many days can A alone do it?**

- (a) 36
- (b) **18  <-- CORRECT**
- (c) 24
- (d) 20

> **Why:** A is twice as fast, so their work rates are in ratio 2:1 and A does 2/3 of the total. Combined they take 12 days, so A alone takes 12 x 3/2 = **18 days** (and B alone 36). The trap is inverting the ratio - remember **faster worker, fewer days**.



## 4.10 Time, Speed, Distance, Trains and Boats



**Q. [PYQ-TYPE] [NUMERICAL] Convert 72 km/hr into m/s.**

- (a) 25
- (b) **20  <-- CORRECT**
- (c) 18
- (d) 36

> **Why:** Multiply by 5/18: 72 x 5/18 = **20 m/s**. This conversion appears in almost every train question - make it automatic.



**Q. [PYQ-TYPE] [NUMERICAL] A train 120 m long is running at 54 km/hr. How long will it take to cross a platform 180 m long?**

- (a) 15 s
- (b) **20 s  <-- CORRECT**
- (c) 18 s
- (d) 25 s

> **Why:** Total distance = train + platform = 120 + 180 = 300 m. Speed = 54 x 5/18 = 15 m/s. Time = 300/15 = **20 seconds**. For a **pole**, the distance would be only the train's length.



**Q. [EXPECTED] [NUMERICAL] [TRAP] A man travels from A to B at 40 km/hr and returns at 60 km/hr. Find his average speed.**

- (a) 50
- (b) **48  <-- CORRECT**
- (c) 45
- (d) 55

> **Why:** Equal **distances**, so use the harmonic mean 2xy/(x+y) = (2 x 40 x 60)/100 = **48 km/hr**. The trap answer 50 is the simple average, which would only be right if he spent equal **time** at each speed.



**Q. [EXPECTED] [NUMERICAL] A boat goes 20 km downstream in 2 hours and returns in 4 hours. Find the speed of the stream.**

- (a) 2.5
- (b) **2.5  <-- CORRECT**
- (c) 5
- (d) 7.5

> **Why:** Downstream speed = 20/2 = 10 km/hr; upstream = 20/4 = 5 km/hr. Stream speed = (down - up)/2 = (10-5)/2 = **2.5 km/hr**, and boat speed = (10+5)/2 = 7.5.



**Q. [EXPECTED] [NUMERICAL] Two trains 100 m and 150 m long run in opposite directions at 40 km/hr and 50 km/hr. How long to cross each other?**

- (a) 12 s
- (b) **10 s  <-- CORRECT**
- (c) 9 s
- (d) 15 s

> **Why:** Opposite directions, so **add** the speeds: 90 km/hr = 25 m/s. Total distance = 100 + 150 = 250 m. Time = 250/25 = **10 seconds**.



## 4.11 Mensuration



**Q. [PYQ-TYPE] [NUMERICAL] The area of a square is 144 sq cm. Find its perimeter.**

- (a) 36 cm
- (b) **48 cm  <-- CORRECT**
- (c) 24 cm
- (d) 60 cm

> **Why:** Side = sqrt144 = 12 cm. Perimeter = 4 x 12 = **48 cm**.



**Q. [PYQ-TYPE] [NUMERICAL] The radius of a circle is 7 cm. Find its area. (Take pi = 22/7)**

- (a) 44
- (b) **154  <-- CORRECT**
- (c) 77
- (d) 308

> **Why:** Area = pi r^2 = (22/7) x 49 = **154 sq cm**. Note the circumference would be 44 cm - the options deliberately include it.



**Q. [EXPECTED] [NUMERICAL] The volume of a cube is 216 cubic cm. Find its total surface area.**

- (a) 144
- (b) **216  <-- CORRECT**
- (c) 180
- (d) 252

> **Why:** Side = cube root of 216 = 6 cm. Surface area = 6a^2 = 6 x 36 = **216 sq cm**. (A coincidence worth noting: for a = 6 the volume and surface area are numerically equal.)



**Q. [EXPECTED] [NUMERICAL] [TRAP] If the radius of a circle is doubled, its area becomes:**

- (a) double
- (b) **four times  <-- CORRECT**
- (c) three times
- (d) same

> **Why:** Area varies as **r^2**, so doubling the radius multiplies the area by **4**. The same logic applies in 3D: doubling the radius of a sphere multiplies its volume by 8.



**Q. [EXPECTED] [NUMERICAL] Find the area of an equilateral triangle of side 6 cm.**

- (a) 18 sqrt3
- (b) **9 sqrt3  <-- CORRECT**
- (c) 36 sqrt3
- (d) 6 sqrt3

> **Why:** Area = (sqrt3/4) a^2 = (sqrt3/4) x 36 = **9 sqrt3 sq cm**.



## 4.12 Data Interpretation



### 4.12.1 The method


DI questions look time-consuming but are usually the easiest marks in the maths section, because they need no formula recall - only careful reading.


*THE DI METHOD*
```
Step 1: Read the TITLE and the UNITS first. "Figures in lakhs" or
        "in percent" changes everything.
Step 2: Read the axis labels and the legend before any question.
Step 3: Answer questions in order of ease - direct reading first,
        then differences, then percentages, then ratios, then averages.
Step 4: Do NOT calculate precisely when the options are far apart.
        Approximate aggressively and match.
Step 5: For "percentage increase", the base is always the EARLIER value.
```



> **TIP: The approximation habit that saves minutes**
>
> If the question asks for a percentage and the options are 12%, 18%, 24% and 31%, you do not need two decimal places - you need the right bracket. Round to convenient numbers, compute, and match. Candidates who compute exact values in DI run out of time in the maths section.



**Q. [EXPECTED] [NUMERICAL] A student scored 60, 75, 80, 45 and 90 in five subjects, each out of 100. What is his overall percentage?**

- (a) 68%
- (b) **70%  <-- CORRECT**
- (c) 72%
- (d) 65%

> **Why:** Total = 350 out of 500. Percentage = (350/500) x 100 = **70%**.



**Q. [EXPECTED] [NUMERICAL] In a pie chart of total expenditure Rs. 7200, the sector for food is 100 degrees. Find the amount spent on food.**

- (a) 1800
- (b) **2000  <-- CORRECT**
- (c) 2400
- (d) 1600

> **Why:** A pie chart's full circle is 360 degrees, so food = (100/360) x 7200 = **Rs. 2000**. Formula: **amount = (sector angle / 360) x total**.
